# Industrial Anomaly Detection — Smart Process System

AI-powered anomaly detection system for chemical process monitoring.
Uses the Tennessee Eastman Process (TEP) simulation dataset to detect
process anomalies, explain root causes, and support operational optimization.

## Project Goal

Beyond simple threshold-based alerts, this system aims to detect anomalies,
explain the likely root cause in natural language, and suggest operational
actions — combining domain knowledge with AI.

## Dataset

Tennessee Eastman Process Simulation Dataset (Kaggle):
https://www.kaggle.com/datasets/averkij/tennessee-eastman-process-simulation-dataset

Download the RData/CSV files and place them in your local `~/Downloads/` folder,
or update `DATA_DIR` in each script to point to your data location.
